# Finance Module

Modular feature directory for Finance domain logic.

## Directory Structure
- `assets/`: Domain-specific images, icons, or graphics.
- `components/`: UI components exclusive to the finance module.
- `constants/`: Constant configuration values.
- `hooks/`: Custom React hooks for finance business logic.
- `pages/`: Page views for finance routes.
- `routes/`: Module routing definitions.
- `services/`: API integration services.
- `store/`: Redux state slices for finance.
- `utils/`: Utility helper functions.
